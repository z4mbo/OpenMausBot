## What people receive

The published [release notes](../../origin-0.7.6-release-notes.md) contain eleven canonical changes under “Shared model continuity and safer project work.” Conversations can recover a missing transcript after a late thread update and offer explicit retry. Agents can have up to five ordered backup models: opt-in fallback starts only after a confirmed quota refusal before work begins, partial work is not replayed, and a paid API backup needs separate consent.

Daily USD budgets apply to the computer and optional agents, with a chosen reset time zone and conservative reservations for supported requests. Shared model sources identify their owner and computer, retain credentials on that computer, and preserve project access, monthly admission, daily budgets and uncertain-work leases. Shared Chiefs/agents and project order survive joining from another computer; specialists, independent threads, delegated conversations and notification targets keep their identities.

Usage details sit beside model selection, hidden conversations cannot open a second Usage portal, and Compact/Medium/Wide chat layouts retain alignment. Narrow budget and Studio Design controls remain reachable. Publish requires confirmed connections and an explicit available account while preserving drafts and approvals. Dedicated Claude API connections retain the selected key and report API-key billing as metered. Private project budgets, trusted Studio attribution and credential-redacted integration errors retain their access boundaries. The integration preserves the newer 0.7.1 product work and explicit Sales/Pipeline/public-Canvas removals; legacy backend tables were retained for existing data. These describe the shipped product; the named acceptance below does not extend to real invoices, every UI state or actual channel delivery.
