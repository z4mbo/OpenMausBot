# Origin 0.7.4: Shared model continuity and safer project work

2026-10-21

## Ordered model backups

Choose up to five backup models for an agent, including supported teammate sources. Opt-in fallback follows that order after a confirmed quota refusal before any reply or action. Partial work is never replayed automatically, and paid API backups need separate consent.

## Daily API budgets

Set a daily USD limit for this computer and optional agent limits, with a reset time zone. Supported API requests reserve their maximum cost before sending; uncertain costs keep their reservation. Unpriced Studio generations, paid transcription and AI calls stop when an applicable limit is active, including Studio workflows.

## Opt-in teammate model sources

Owners can share supported model accounts with selected projects. Choices identify the owner and computer, keep credentials on that computer and require it to be online. Hosted work checks project access, monthly limits and the owner's daily API limits, with leases that prevent uncertain work from silently moving to another account.

## Shared identity and project order

Joining from another computer preserves existing shared Chiefs and agents. Project ordering follows the workspace across members, while private projects and read-only permissions keep their boundaries.

## Specialists keep their conversations

Agents lists specialists without the project Chief. Independent threads and delegated work stay separate, Chief follow-ups return to the same delegated child, and notifications open the exact conversation with a link back to its project thread.

## Minimal Usage and chat layouts

Open quota and reset details beside the model selector, with context details available on demand. Hidden conversations cannot open a second Usage panel. Compact, Medium and Wide layouts keep the composer and conversation aligned.

## Safer Publish account selection

Publish waits for confirmed channel connections and an available selected account. Removing an extra account cannot silently post through another one. Drafts and approvals remain available while connections are unavailable.

## Narrow windows stay usable

Monthly budget details fit behind a compact control. Studio Design keeps Layers and Design controls reachable while its tools scroll, without moving the canvas or hiding the panel controls.

## Claude API connections

The dedicated Claude API connection keeps its saved key when the workspace also uses that key for other Claude agents. Connections using an API key report metered billing even when a separate CLI sign-in reports a subscription.

## Project boundaries and private errors

Private project budgets require project access. Studio preserves caller identity and budget checks across workflow steps, and integration errors remove configured credentials before reaching shared data or chat.
