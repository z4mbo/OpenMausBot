## Preserve Origin semantics

Upstream automatic sole-Cloud-home migration, paid Cloud plans and Admin-signed Team Cloud authority do not match Origin accounts, Convex workspace/project access and sender-runs sharing. Origin’s explicit saved-server Copy uses encrypted whole-workspace backup rather than the new upstream per-item cloud-send state machine. The shared-screen late-renewal scenario is already blocked by Origin’s server lease-existence guard; new-bot dialog stacking and saved routine names also have present equivalents.

Adopt one narrow change at a time: pin the upstream merge and diff, reproduce the exact Origin branch with synthetic state, add negative project/member/host cases, then make a logical fix commit. Preserve human-approved merges and refuse replay after uncertain or partial work. An eventual application release needs a new version, canonical app/site changelog and exact-source platform/release checks. This source review does not reopen any held operator or the completed 0.7.6 delivery.
