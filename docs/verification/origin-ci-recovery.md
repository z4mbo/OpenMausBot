## Cross-drive reproduction and the next candidate

[Diagnostic CI 39121184420](https://github.com/z4mbo/Origin/actions/runs/39121184420), source `16fda399b834ce24d8b895f6a082bf32030444be`, completed with failure in Windows shard 2.
