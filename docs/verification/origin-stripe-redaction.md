# Stripe credential content redaction

Upstream [OpenMausBot #3037](https://github.com/milind-soni/OpenMausBot/pull/3037), merge `170a58bc55c90dc8548a99b533dce6e9b1216496`, is adapted in worker source `26150a3ed34c480092060ec7916edbc538f405db` and integration commit `5b1ffceb4`. This is one verified source adaptation after the immutable [twenty-six-PR initial checkpoint](evidence/origin-upstream-review-20261018-172407/manifest.json); that checkpoint's zero-adoption record remains unchanged. Publication requires its own later release acceptance.

The conditional P1 defect is reachable when provider output contains a Stripe secret or restricted key in ordinary text. The production Claude driver passes its structured provider frame to the native protocol writer; that writer calls the shared content scrubber before persisting NDJSON. The former hyphenated provider-key pattern does not recognize Stripe's underscore prefixes, so the actual native log retains the synthetic credential value. No real key was used or searched for.

The shared scrubber now recognizes `sk_live_`, `sk_test_`, `rk_live_` and `rk_test_` followed by at least sixteen alphanumeric characters. It preserves stable length-only markers, publishable keys, short documentation examples and ordinary text. The implementation remains shared by native logs, nested protocol objects and the other existing content-redaction callers. Existing historical logs are not rewritten.

The unchanged regression selection fails five cases and passes twenty-two before the source fix, then passes all twenty-seven afterward. Four cases cover exact/longer token boundaries, nested objects, idempotence and ordinary identifiers. The integration case launches the documented isolated fake-Claude server, performs a real API/headless send and inspects the actual provider-native NDJSON. All four synthetic values are absent after the fix, while the expected four markers and surrounding text remain. The fixture closes in `finally` on both runs.

The consumer and guard selection passes 194 tests, with nine existing Windows exclusions for POSIX permissions, decision-log wiring and a diagnostics symlink. Application/server TypeScript, focused lint and whitespace checks pass. The [sanitized report](evidence/origin-stripe-redaction-032/report.json) binds source blobs, private raw-log hashes and exact outcomes; its [manifest](evidence/origin-stripe-redaction-032/manifest.json) preserves the public evidence bytes. Logs containing local fixture paths stay private. No production account, real provider, recipient email, push or deployment was used for this verification.
