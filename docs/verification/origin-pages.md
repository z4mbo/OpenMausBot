# Origin production project pages

This fixture renders production Issues, issue details/composer/completion, Assets/tokens, Vault, Feedback, Repo, project Settings, workspace Inbox/calendar, workspace Chat, workspace Members and account menu/settings components. Cloud hook results and GitHub/local-chat HTTP responses are synthetic. It starts a disposable fake-engine server through `scripts/control-omb.ts`; it never connects an Origin account, the user's running app, local Convex or a real GitHub repository.

## Rejected queries and offline transport

The source audit found that `useCloudQuery` and paginated reads collapsed rejected query results into `undefined`. Gates had a stalled-state retry, but already-loaded page children remained skeletons indefinitely. Four regressions failed before the change. An opt-in failure scope now catches rejected queries and 12-second unresolved initial reads around project/workspace pages and workspace members. Initial failures show a shared, sanitized failure state with explicit retry. Refresh failures retain the last successful data and any unsaved editor; their retry refreshes subscriptions without remounting that editor. Shared Modal and IssueDialog display recovery controls inside the focus trap as well as in the page header. Authoritative `auth:me`, `projects:get` and `workspaces:access` failures discard cached access and remove private children. The boundary also resets on project, workspace, account/session and backend changes. Unrelated hook callers retain their existing undefined-result contract; programming errors propagate instead of being hidden as network failures. Initial recovery is committed as `91e477f8e`.

The installed Convex SDK is `1.47.0`. Its `web_socket_manager.ts` caps reconnect backoff at 16 seconds before jitter, which can extend it to 24 seconds. Explicit retries therefore get a bounded 30-second window; using the initial 12-second deadline for retry could fail again before the SDK was due to reconnect. This keeps the existing shared client and its subscriptions intact. A regression proves the initial deadline, the extra retry window and its eventual bound; the actual server-restart protocol case also recovers through the explicit retry. Commit `a751a37bc`.

The fixture records only event/query names and outcomes, excluding query arguments.

Its protocol event log includes the reruns performed against that fixture.
