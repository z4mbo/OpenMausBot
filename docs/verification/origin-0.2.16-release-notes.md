# Origin 0.2.16: Model continuity and shared project work

2026-10-20

## Ordered model backups

Choose up to five backup models for each agent. Opt-in fallback follows that order when a provider confirms its quota is exhausted. Automatic continuation requires a refusal before any reply or action; work already started is never sent again automatically. Paid API backups need separate permission.

## Daily API budgets

Set a daily USD limit for this computer and optional limits for individual agents, with a chosen reset time zone. Supported API requests reserve their maximum cost before sending. Uncertain costs keep their reservation; unsupported or unpriced routes stop when a limit applies. Confirmed subscription models remain available.

## Shared agents keep their identity

Workspace and project synchronization preserves existing shared-agent identities when another computer joins. A sync round reconciles imported Chiefs and agents before continuing, and an account change discards the previous round.

## Project order follows the workspace

Reorder shared projects with a pointer or keyboard and see the order on other members' computers. Private projects stay private, and read-only access cannot change the shared order.

## Specialist conversations stay separate

The project Agents page lists each specialist's independent and delegated conversations. Chief follow-ups return to the same delegated child, leaving your direct conversation in place. Notifications open the exact child, with a link back to its project conversation.

## A quieter Usage panel

Open a compact quota panel from the agent conversation header and expand context details when needed. Unavailable quota checks stay neutral. Appearance offers Compact, Medium and Wide layouts that keep the conversation and composer aligned on this device.

## Opt-in teammate model sources

Share supported model accounts with selected projects. Shared choices identify the owner and computer, run on that owner's device and keep provider credentials there. Ordered backups can cross local and teammate sources after a safe initial quota refusal. Paid sources require consent and the owner's budget checks; partial or uncertain accepted work is not silently replayed.
